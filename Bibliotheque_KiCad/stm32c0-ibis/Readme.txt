===============================
IBIS files for STM32C0 devices:
===============================

The package contains :
   

   + IBIS Files for STM32C011 devices on different packages :

	  o UFQFPN20
	  o TSSOP20
	  o WLCSP18
	  o SO8N

   + IBIS Files for STM32C031 devices on different packages :

	  o LQFP48
	  o UFQFPN48
	  o LQFP32
	  o UFQFPN32
          o UFQFPN28
	  o TSSOP20


   + IBIS Files for STM32C071_GP devices on different packages :
      
	  o LQFP64
	  o UFQFPN48
	  o LQFP48
	  o UFQFPN32
	  o LQFP32
	  o UFQFPN28
	  o TSSOP20
          o WLCSP19

  + IBIS Files for STM32C071_N devices on different packages :
	  o LQFP64
	  o UFBGA64
	  o UFQFPN48
	  o LQFP48
	  o UFQFPN32
	  o LQFP32
	  o UFQFPN28
	  o TSSOP20

 + IBIS Files for STM32C051 devices on different packages :

	  o LQFP28
	  o LQFP32
	  o LQFP48
	  o TSSOP20
          o UFQFPN32
          o UFQFPN48
          o WLCSP15


 + IBIS Files for STM32C091_092 devices on different packages :

	  o LQFP32
	  o LQFP48
	  o LQFP64
	  o TSSOP20
          o UFBGA64
          o UFQFPN28
          o UFQFPN32
          o UFQFPN48
          o WLCSP24
